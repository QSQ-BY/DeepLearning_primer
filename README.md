## Task 1：NumPy 神经网络运算框架

用 NumPy 和 Python 标准库从零实现一个小型神经网络框架，练习各层的前向传播、反向传播和参数更新。支持全连接与卷积网络，在 Fashion-MNIST 小规模实验中的最高测试准确率为 **82.10%**。

- [AIGC 协作文档](task1_简单神经网络运算框架的实现/docs/AIGC/)

## Task 2：TextCNN 新闻分类

用 PyTorch 搭建 TextCNN，完成 AG-news 英文新闻四分类，包括数据处理、训练、评估和单条预测。经过多组调参，最终单次实验的测试准确率为 **92.0132%（6993 / 7600）**。
