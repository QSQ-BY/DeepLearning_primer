# 学习日志：从线性回归正式走进深度学习

> 日期：2026 年 8 月 18 日至 8 月 20 日  
> 学习资料：[《动手学习深度学习（PyTorch 版本）》](https://tangshusen.me/Dive-into-DL-PyTorch/)

## 8 月 18 日：第一个模型是线性回归

这几天算是正式进入了深度学习的学习。之前学 Tensor 和自动求梯度时，我接触到的还是一个个相对独立的操作；到了线性回归，数据、模型、损失函数和参数更新第一次被接成了完整流程。

线性回归的数学逻辑并不陌生。高中阶段已经接触过了，现在只是把一个自变量扩展成多个特征，用矩阵来同时表示一批数据。代码先按照已知的权重和偏置生成 1000 个样本，再给标签加上一点随机噪声：

```python
num_examples = 1000#训练集总数
num_inputs = 2#训练集变量数
features= tc.randn(num_examples,num_inputs,dtype = tc.float32)
true_w = [2,-3.4]
true_b = 4.2
labels = true_w[0]*features[:,0] + true_w[1]*features[:,1] + true_b
labels += tc.normal(0,0.01,size = labels.size(),dtype = tc.float32)
```

这里的 `features` 不再是一列普通数字，而是一个 1000 行、2 列的矩阵：每一行是一条样本，每一列是一个特征。模型要做的事情，是根据这些样本重新估计出接近 `[2, -3.4]` 的权重和接近 `4.2` 的偏置。

这一步本身不难，真正让我慢下来的还是 Tensor 的形状。以前写算法题时，我通常盯着一个变量、一个数组位置或者一段区间；现在每做一次乘法，都要先想清楚矩阵的行列能不能对应、结果会是什么形状，以及偏置会怎样广播到整批样本上。

## 8 月 19 日：把训练循环从头串起来

接下来是从零实现线性回归。模型只有一句矩阵乘法：

```python
def linreg(X,w,b):
    return tc.mm(X,w)+b#mm为矩阵乘法
```

但要真正让它学出参数，还要把小批量读取、前向传播、损失计算、反向传播和随机梯度下降放到同一个循环里：

```python
for epoch in range(num_epochs):
    for X,y in d2l.data_iter(batch_size,features,labels):
        y_hat = linreg(X,w,b)
        loss = d2l.squared_loss(y_hat,y).sum()
        loss.backward()
        d2l.sgd([w,b],lr,batch_size)

    with tc.no_grad():
        train_loss = d2l.squared_loss(linreg(features,w,b),labels).mean()
```

现在回头看，这个循环的逻辑其实很规整：先拿一批数据算出预测值，再计算预测值和真实标签之间的距离；`backward()` 把梯度算出来，`sgd()` 根据梯度更新 `w` 和 `b`。一个 epoch 结束后，再用完整训练集看一次平均损失。

困难不在于步骤有多绕，而在于每一步都带着我不熟悉的 PyTorch 接口。`mm()`、`view()`、`index_select()`、`backward()`、`no_grad()`，再加上梯度清零和批量大小对更新量的影响，我几乎一直对着课本往下敲。为了不让自己只剩下“代码能运行”的印象，我给每个新函数都补了说明，最后注释比真正执行的代码还多。

这和写算法题的感觉很不一样。算法题往往是先想清楚思路，再选择数据结构把它表达出来；这次模型的主线很早就能看懂，我花掉的大部分时间却是在确认张量形状、矩阵乘法和框架接口到底怎样配合。

## 8 月 20 日：简洁实现，以及 Softmax 前的准备

之后我又跟着书写了 PyTorch 提供的简洁版本。原来由自己维护的参数、损失和更新过程，都能交给框架里的模块处理：`TensorDataset` 把特征与标签组合起来，`DataLoader` 负责分批和打乱，`nn.Linear` 保存线性层参数，优化器则完成梯度更新。

```python
dataset = Data.TensorDataset(features,labels)
data_iter = Data.DataLoader(dataset,batch_size,shuffle = True)

# ... 省略 LinearNet 定义与参数初始化
net = LinearNet(num_inputs)
loss = nn.MSELoss()
import torch.optim as optim
optimizer = optim.SGD(net.parameters(),lr = 0.03)

# ... 省略 epoch 外层循环
for X,y in data_iter:
    output = net(X)#向前传播
    l = loss(output,y.view(output.size()))
    optimizer.zero_grad()
    l.backward()
    optimizer.step()
```

简洁实现的代码短了很多，但不代表可以跳过前面的手动实现。只有先亲自写过平方损失和随机梯度下降，我才知道 `nn.MSELoss()` 与 `optimizer.step()` 替我收起了哪些细节；否则这些 API 很容易变成几句只会照抄的固定咒语。

线性回归之后，我开始学习 Softmax 回归。线性回归输出的是一个连续数值，而分类问题需要在多个类别之间作出选择。Softmax 会把模型对每个类别给出的分数转换成概率：

\[
\hat y_j=\frac{\exp(o_j)}{\sum_k\exp(o_k)}
\]

转换之后，每个类别的结果都大于 0，并且总和为 1。Fashion-MNIST 一共有 10 个类别，所以模型最终会给每张图片输出 10 个分数，再配合交叉熵衡量预测结果与真实标签之间的差距。

为了给下一阶段准备数据，我还在通用模板库里写了 Fashion-MNIST 的加载流程。训练集和测试集使用同一套图片变换，但通过 `train` 参数区分用途：

```python
train_dataset = torchvision.datasets.FashionMNIST(
    root = data_root,
    train = True,
    transform = transform,
    download = True,
)

test_dataset = torchvision.datasets.FashionMNIST(
    root = data_root,
    train = False,
    transform = transform,
    download = True,
)
```

完整的数据流程是先根据需要调整图片尺寸，再把图片转换成 Tensor，接着分别建立训练集和测试集，最后交给 `DataLoader` 按批次读取。训练集要打乱顺序，测试集则保持稳定。这部分还没有进入 Softmax 模型本身，但已经让我看到，真实模型的输入不会像线性回归练习那样直接在代码里随机生成，数据下载、变换和分批也是训练流程的一部分。

## 先停一天，把流程看熟

所以明天先不急着继续实现 Softmax。我想把这次写下来的两种线性回归重新过一遍，逐行确认数据怎样被分批、预测值怎样算出、损失怎样传回梯度，参数又怎样完成一次更新。等这些函数不再每次都要翻书，Softmax 的代码才不会只是在相同位置换上一批新的 API。当然，也可能还是得先跟着书再敲一遍，但至少下一遍应该知道自己为什么要写这一行。
