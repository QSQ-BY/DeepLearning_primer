# 8 月 24 日：把 Linear 的反向传播接起来

今天继续搭 NumPy 神经网络框架，主要完成了 `Linear` 层的反向传播。和前向传播一样，这部分没有直接从实现代码开始，而是先写测试，再让失败结果指出当前缺少的行为。到最后，输入梯度、权重梯度、偏置梯度、参数接口、调用顺序检查和数值梯度检查一共积累了 13 项测试，当前全部通过。

前向传播只有一行核心公式：

\[
Y=XW+b
\]

反向传播则要接住后续网络传回来的 `grad_output`，也就是损失对当前层输出的梯度：

\[
G=\frac{\partial L}{\partial Y}
\]

然后分别计算：

\[
\frac{\partial L}{\partial X}=GW^\mathsf T,
\qquad
\frac{\partial L}{\partial W}=X^\mathsf TG,
\qquad
\frac{\partial L}{\partial b}=\sum_{\text{batch}}G
\]

我花了不少时间追问这些式子为什么成立，尤其是为什么对输出的梯度乘上权重转置，就得到了对输入的梯度。把矩阵拆成元素后，答案其实来自链式法则：一个输入特征会同时影响这一层的多个输出，因此它对损失的总影响，要把所有输出方向上传回来的梯度按对应权重加起来。矩阵里的转置不是为了凑形状，而是让输出维度正确地参与求和。

目前的反向传播实现如下：

```python
def backward(self,grad_output):
    if(self.__input is None):
        raise RuntimeError(
            "Linear.backward() requires forward() first"
        )

    grad_output = np.asarray(grad_output)

    # ... 省略 grad_output 形状检查 ...

    self.grad_weight[::] = self.__input.T @ grad_output
    self.grad_bias[::] = grad_output.sum(axis = 0)
    return grad_output @ self.weight.T
```

这里必须在前向传播时缓存输入 `X`，因为计算 `grad_weight` 时还会用到它。如果没有先调用 `forward()`，`backward()` 会主动抛出带有明确说明的 `RuntimeError`。`grad_output` 的形状也必须与本层输出一致，也就是 `(batch_size, out_features)`。这些检查仍然是由测试先提出要求，再补上最小实现。

我也弄清了 `axis=0` 在偏置梯度中的意思。它会消掉批次这个维度，把不同行的对应元素上下相加，最终为每个输出特征留下一个偏置梯度。这里不是“每行求和”，而是对所有样本在同一输出位置上的贡献求和。

除了梯度计算，`Linear` 现在还提供了 `parameters()` 和 `gradients()`。它们分别返回 `[weight, bias]` 和 `[grad_weight, grad_bias]`，顺序一一对应。测试使用 `assertIs()` 检查返回值是不是原来的数组对象，而不只是数值相同。以后 SGD 拿到这些引用后，才能真正修改模型里的参数。梯度数组同样采用原地覆盖，避免优化器保存的引用失效。

今天最费时间、也最有价值的一项测试是有限差分梯度检查。它不再拿手算答案和代码结果直接比较，而是逐个改变权重，重新执行前向传播：

```python
for index in np.ndindex(layer.weight.shape):
    original = layer.weight[index]

    layer.weight[index] = original + epsilon
    plus = np.sum(layer.forward(x)*grad_output)

    layer.weight[index] = original - epsilon
    minus = np.sum(layer.forward(x)*grad_output)

    layer.weight[index] = original
    numerical[index] = ((plus - minus)/(2*epsilon))
```

这里先构造标量函数：

\[
L=\sum_{i,j}Y_{ij}G_{ij}
\]

于是它对 `Y` 的梯度刚好就是给定的 `grad_output`。对某一个权重分别加上、减去很小的 \(\varepsilon\)，再用中心差分：

\[
\frac{L(W_{ij}+\varepsilon)-L(W_{ij}-\varepsilon)}{2\varepsilon}
\]

就能估算这个权重的数值梯度。它速度很慢，不会用于真正训练，但很适合检查自己写的反向传播。解析梯度和数值梯度最终在误差范围内一致，这比单独通过一组确定值测试更让我放心，因为两种结果来自不同的计算路径。
