## 先给线性模型加一层

学完 Softmax 回归后，我继续实现多层感知机。它和前面的分类模型有一段很熟悉的开头：Fashion-MNIST 图片仍然要展平成 784 维向量，最后也要得到 10 个类别分数。中间多出来的是一个包含 256 个单元的隐藏层，以及隐藏层之后的 ReLU。

手写版本的核心前向计算很短：

```python
def relu(X):
    return torch.max(input = X,other = torch.tensor(0.0))

#定义模型
def net(X):
    X = X.view((-1,num_inputs))
    H = relu(torch.matmul(X,w1) + b1)
    return torch.matmul(H,w2) + b2
```

第一组参数把输入从 784 维映射到 256 维，ReLU 把隐藏层中的非正数截成 0，第二组参数再把 256 个隐藏特征变成 10 个类别分数。这里的 ReLU 不能省掉。如果两个线性层之间没有非线性，不管中间维度多大，连续的矩阵乘法最后仍然可以合并成一次线性变换，多加一层也不会让模型表达出更复杂的关系。

随后我用 `nn.Sequential` 写了简洁版本，把 `FlattenLayer`、两个 `nn.Linear` 和 `nn.ReLU` 按顺序连接起来。两份代码做的是同一件事，但观察角度不同：手写参数时，我能直接看到 `W1`、`b1`、`W2`、`b2` 的形状和数据流；换成 PyTorch 层以后，参数注册、梯度保存和更新都藏进了统一接口。这个对照正好接上了后面几天的框架实现，我需要补出的内容既有公式，也有层与层之间的约定。

## 把框架缺少的部件补齐

之前的 NumPy 框架已经完成 `Linear` 的前向和反向传播。这几天继续加入了 ReLU、Softmax 交叉熵损失、`Sequential` 和 SGD。

ReLU 的反向传播会使用前向阶段保存的正值掩码：输入大于 0 的位置允许梯度通过，其余位置返回 0。它本身没有可训练参数，但仍然实现了 `parameters()` 和 `gradients()`，并返回空列表。这样 `Sequential` 汇总参数时不必判断当前层属于哪一种类型。

Softmax 和交叉熵被放进同一个损失类。直接计算指数时，大的 logits 很容易溢出，因此前向传播先让每个样本的 logits 减去该行最大值：

```python
shifted_logits = logits - logits.max(
    axis=1,
    keepdims=True,
)#对于每一行，减去该行的最大值避免造成数据超出范围，
#相当于最后计算概率的时候上下同时除以e的max次方
exponentials = np.exp(shifted_logits)
#axis = 1，对每一行求和保留每一列
sums = exponentials.sum(axis=1,keepdims = True)
probabilities = exponentials / sums
```

Softmax 对同一行的所有指数同时缩放，减去相同常数不会改变最后的概率，却能把最大的指数固定在 `e^0=1` 附近。交叉熵也没有再对一个可能已经下溢成 0 的概率直接取对数，而是使用平移后的正确类别分数和 `log(sums)` 计算损失。反向传播得到的结果是 `(probabilities - one_hot(labels)) / batch_size`，可以直接送回网络。

`Sequential` 负责处理层的顺序。前向传播从第一层走到最后一层，上一层的输出就是下一层的输入；反向传播则倒序调用每一层，把梯度一层层传回去。它还按层的顺序收集参数和梯度，因此 SGD 只需要让两个列表保持一一对应，就能原地执行 `parameter -= learning_rate * gradient`。

## 训练闭环终于跑起来了

最后我用三团二维数据检查这些部件能不能真正协作。网络结构是 `Linear(2, 16) → ReLU → Linear(16, 3)`，训练循环只保留四个动作：

```python
for epoch in range(301):
    logits = network.forward(features)
    loss_value = loss_function.forward(logits, labels)
    network.backward(loss_function.backward())
    optimizer.step()
```

一次循环里，网络先算出三个类别的 logits，损失函数保存 Softmax 概率和标签，再把对 logits 的梯度交给 `Sequential.backward()`。梯度依次经过第二个 `Linear`、ReLU 和第一个 `Linear`，四组参数梯度随之写入原数组，最后由 SGD 更新权重和偏置。下一轮前向传播读到的已经是更新后的参数，训练闭环就这样接上了。

当前测试一共 50 项，覆盖了层的数值计算、错误输入、调用顺序、有限差分梯度检查、参数收集、优化器更新和端到端训练，全部通过。玩具分类器从第 0 轮的 `loss=1.268683`、`accuracy=34.00%`，训练到第 300 轮时的 `loss=0.013734`、`accuracy=99.67%`。这次结果比单独测试某个矩阵公式更完整：损失确实下降，说明前向计算、梯度传播和参数更新至少在这个小网络里能够互相配合。

这里完成的是框架的最小训练闭环。卷积层、Batch Normalization 等扩展还没有实现，我也不打算把它们提前算进这次进度。现在再看 PyTorch 里的 `nn.Sequential`、`CrossEntropyLoss` 和 `SGD`，我能把这些名字和层的缓存、反向传播顺序、参数引用、优化器更新一一对应起来，也知道一次 `loss.backward()` 与 `optimizer.step()` 背后有哪些数据在流动。下一次继续扩展框架时，我会沿着这套约定加入新的层，训练流程本身已经不用再从头猜了。
