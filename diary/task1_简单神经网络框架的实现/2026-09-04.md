# 9 月 4 日：把卷积层接进第一个可训练的小型 CNN

昨天写完 `Conv2D` 时，卷积层还只是一个能够单独完成前向和反向传播的模块。今天我补上了 `Flatten`，再把 `Conv2D`、`ReLU`、`Flatten` 和 `Linear` 串进同一个 `Sequential`，终于用自己的框架跑通了第一个小型卷积网络。

这一步的代码不算多，但它检验的东西比单独测试一层更完整：四维特征图能否交给二维线性层，梯度能否沿原路恢复形状，卷积层和线性层的参数能否一起被优化器更新。直到损失真正下降，我才算确认前面做的几个组件能够配合工作。

## Flatten 做的事很少，却补上了层与层之间的接口

卷积层输出 NCHW 格式的四维张量，而 `Linear` 接收的是 `(batch_size, features)` 二维输入。`Flatten` 的任务，就是保留批次维，把每个样本剩下的维度合并成一个特征向量。

```python
def forward(self,x):
    x = np.asarray(x)
    batch_size = x.shape[0]
    output = x.reshape(batch_size,-1)
    self.__input_shape = x.shape
    self.__output_shape = output.shape
    return output

def backward(self,grad_output):
    if(self.__input_shape is None or self.__output_shape is None):
        raise RuntimeError("Flatten.backward() requires forward() first")
    grad_output = np.asarray(grad_output)
    expected_shape = self.__output_shape
    actual_shape = grad_output.shape
    if actual_shape != expected_shape:
        raise ValueError(
            f"Flatten expected grad_output shape {expected_shape}, "
            f"but received {actual_shape}"
        )

    return grad_output.reshape(self.__input_shape)
```

前向传播中的关键是 `reshape(batch_size, -1)`。例如 `(3, 2, 8, 8)` 会变成 `(3, 128)`：3 个样本仍然分开，每个样本的两个通道和空间位置被排成一行。反向传播不需要求新的导数，只要把上游传来的 `(3, 128)` 恢复成缓存的 `(3, 2, 8, 8)`，梯度就能继续交给前面的 `ReLU` 和 `Conv2D`。

我也为它保留了框架已有的统一接口。`Flatten` 没有权重和偏置，所以 `parameters()` 与 `gradients()` 都返回空列表；`Sequential` 不必为它增加特殊判断。测试则覆盖了逐样本展平、反向恢复形状和值、错误梯度形状，以及未执行 `forward()` 就调用 `backward()` 的情况。

今天真正明确下来的是，神经网络层之间传递的不只是数值，形状本身也是接口的一部分。`Flatten` 没有改变元素，也没有可训练参数，但它知道怎样把两个结构不同的层接起来，并让反向传播按同一条路径返回。

## 用横线和竖线检查完整训练链路

为了不把框架验证绑在数据下载和文件读取上，我生成了 `8 × 8` 的单通道图像：一类图像中间是竖线，另一类是横线，再叠加少量随机噪声。固定随机种子后，数据可以稳定复现，也足够让卷积核学到两类图案的区别。

网络仍然很小：

```python
network = Sequential(
    Conv2D(
        in_channels=1,
        out_channels=2,
        kernel_size=3,
        padding=1,
        rng=rng,
    ),
    ReLU(),
    Flatten(),
    Linear(2 * 8 * 8, 2, rng=rng),
)
```

它的前向形状依次是：

```text
(N, 1, 8, 8)
-> Conv2D: (N, 2, 8, 8)
-> ReLU:   (N, 2, 8, 8)
-> Flatten:(N, 128)
-> Linear: (N, 2)
```

反向传播则从 `(N, 2)` 倒着经过这些层，最后回到 `(N, 1, 8, 8)`。我先用测试检查了网络两端的形状，再运行完整训练示例。80 个训练样本和 20 个测试样本上，初始损失为 `0.493895`，训练准确率为 `52.50%`；训练 11 轮后，损失降到 `0.056154`，训练集与测试集准确率都达到 `100%`。

这个数据集很简单，因此 100% 不能说明框架已经能处理真实图像任务。不过它完成了当前最需要的验证：损失函数产生梯度，`Sequential` 逆序传递梯度，`Conv2D` 和 `Linear` 保存参数梯度，最后由 `SGD` 原地更新参数。整条链路没有断。
